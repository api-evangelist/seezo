# Seezo

> Seezo is an automated, AI-powered security design review platform. It analyzes design documents and product requirement docs (PRDs) to generate explainable, consistent, contextual security requirements — threat models, data-flow diagrams, and component maps — before developers start coding, and routes those requirements into existing developer tools. Seezo is SOC 2 and ISO 27001 certified. It does not currently publish a public developer API, SDKs, or OpenAPI.

## Product
- [Seezo home](https://seezo.io/): Automated security design review platform.
- [Product Tour](https://seezo.io/product-tour): Walkthrough of the security design review workflow.
- [Web app](https://app.seezo.io): Sign in / sign up; free tier available.
- [Build vs Buy Scorecard](https://seezo.io/build-vs-buy-scorecard): Evaluation tool for teams deciding whether to build or buy design review.

## Integrations
> Seezo connects to existing dev-workflow tools (consumer-side integrations; Seezo does not expose these as its own API): Confluence, Google Docs, SharePoint, Jira, Slack, GitHub, ServiceNow, DevRev, Linear, IcePanel, LucidChart, Notion.

## Identity & Auth
- [OAuth Authorization Server metadata](https://app.seezo.io/.well-known/oauth-authorization-server): RFC 8414 metadata for app.seezo.io — authorization_code + refresh_token grants, PKCE (S256), dynamic client registration.
